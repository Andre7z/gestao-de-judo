Apenas usuários autenticados podem acessar o sistema
Um aluno deve estar cadastrado para participar de uma atividade.
Um aluno deve estar vinculado a uma turma.
O cadastro de um aluno deve possuir CPF válido.
O cadastro de um anexo possuir arquivo de no máximo 10MB.
Um aluno não pode ser vinculado duas vezes à mesma turma.
Ao graduar o aluno, a faixa deve ser posterior à faixa atual.
